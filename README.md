Pickle-Bot application will serve as a GroupMe calendar event manager.  
The Pickle-Bot will manage the number of players who can play by accepting 4, 8, 10, 12, 14 total players.  
Odd number of attendees will be asked to find more people or drop out. 
The theme of the BOT will RELAXED / PICKLEBALL level messages sent to the group.  Some jokes thrown in there will 
add to the fun of this app.
